# Manufacturing AGV Multistep World Model

Research code and frozen evidence for a multistep physics-informed graph counterfactual world model for manufacturing-system AGV decision support.

> **Repository status:** curated public-release candidate. The code, frozen checkpoints, anonymous scenario, confirmatory outputs, and independent AnyLogic validation are included. Restricted factory drawings, identifiable company material, manuscript working files, regenerable development traces, and superseded exploratory runs are intentionally excluded.

## Scope

The repository studies energy-aware and congestion-aware AGV logistics in an anonymous CAD-derived manufacturing scenario with 20 graph nodes and three AGVs. The main evidence chain is:

1. **Multistep prediction:** an equal-parameter physics factorial evaluates physics-referenced supervision and physical node features.
2. **Counterfactual decision value:** frozen models rank feasible action alternatives on unseen trajectories.
3. **Shadow decision support:** an agreement gate issues sparse recommendations without granting direct control authority.
4. **Independent validation:** AnyLogic checks capacity and congestion trends on the same anonymous network and task-flow assumptions.

The repository does **not** claim a real-time bidirectional shop-floor digital twin, statistically established graph superiority, or confirmed closed-loop production improvement.

## Quick Start

Windows PowerShell is the reference shell.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\scripts\00_run_multistep_core_tests.ps1
```

CUDA is optional for analysis and tests. Long training and counterfactual confirmation runs are substantially faster on a CUDA-capable GPU.

## Reproduce the Evidence

Start with [REPRODUCIBILITY.md](REPRODUCIBILITY.md). The main frozen evidence is already available in `experiment_results/`; rerunning every training stage is not required to inspect the paper results.

```powershell
# Verify the curated package before using it
python .\tools\audit_public_release.py

# Rebuild submission figures from frozen source data
python .\tools\build_submission_figures.py

# Reanalyze the independent AnyLogic validation export
powershell -ExecutionPolicy Bypass -File .\scripts\48_analyze_anylogic_validation.ps1
```

## Data and Confidentiality

The manufacturing topology is an anonymous, geometrically simplified derivative of a restricted CAD source. It preserves the decision-relevant routing structure and metric edge lengths but removes company names, product identifiers, architectural details, and the original drawing. Experimental task streams are generated by the disclosed stochastic process; they are not production records.
