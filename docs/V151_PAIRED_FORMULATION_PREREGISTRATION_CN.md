# V15.1 成对差值学习形式消融预注册

## 研究问题

本实验只回答一个问题：在相同数字孪生状态、相同候选动作、相同冻结物理图主干和相同参数预算下，直接学习“候选动作减原动作”的成对效应，是否优于先分别预测两个动作的绝对结果、再相减？

## 冻结设计

- 本文方法沿用三个已冻结的 V14.1 模型，模型种子为 42、43、44。
- 对照方法分别从对应种子的同一个 V13 冻结主干初始化。
- 两种方法都使用同一个 56,457 参数的共享动作价值头；不更新主干。
- 两种方法使用同一份训练缓存、相同训练/验证轨迹划分、优化器、学习率、批量大小、最大轮数和提前停止规则。
- 唯一科学差异是监督目标。本文方法直接监督成对差值；对照方法监督原动作和候选动作的绝对结果，推理时再相减。
- 两种方法都在同一组候选动作上比较，统一使用本文方法从训练集冻结的尺度计算最终效用，防止对照方法使用另一套评价标准。

## 独立确认集

- 数据种子：18400。
- 完整轨迹：12 条。
- 每条轨迹最多 4000 个决策步；前 1200 步为预热。
- 每 80 个决策步抽取一次状态；每个状态最多三个物理可行且与原动作实际不同的候选动作。
- 物理预测时间：120 秒、360 秒和 720 秒。
- 主要终点：720 秒处的动作排序后悔值。
- 统计单位：完整轨迹，而不是单个候选动作。

## 预先冻结的判断标准

协议完整性必须全部满足：

1. 存在 12 条完整确认轨迹。
2. 两种方法评价完全相同的状态和候选动作。
3. 六个模型的预测头均为 56,457 个参数。
4. 两种方法使用同一个训练期冻结评价尺度。
5. 所有排序后悔值均为有限数。

若以下四项全部满足，则支持“直接成对效应学习”这一增量创新：

1. 直接成对学习的平均排序后悔值更低。
2. 轨迹级配对自助法的 95% 区间完全大于零。
3. 至少 9/12 条轨迹支持直接成对学习。
4. 直接成对学习的第一名动作一致率不低于绝对结果对照。

无论结果是否通过，均保留并报告；不得更换种子、效用权重、阈值或确认集。
