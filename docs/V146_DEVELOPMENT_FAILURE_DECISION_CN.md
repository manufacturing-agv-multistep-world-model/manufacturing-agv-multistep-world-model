# V14.6 受限闭环开发实验失败决策

## 决策

V14.6 不进入正式确认实验，不形成闭环产能、能耗或安全优势结论。实验作为完整的负向开发证据保留。

## 已通过部分

- 五个环境种子的两种方法均达到一小时固定物理时间。
- 每个配对实验的外生任务流数量和哈希签名完全一致。
- 没有电量耗尽或超时。
- 每个种子均未增加死锁，平均死锁由 13.0 降至 12.8。
- 平均冲突事件增幅低于预设的 5% 上限。
- 世界模型决策时间的第 95 百分位均远低于 2 秒。
- 权限确实被使用，且未超过每小时 12 次的预算。

## 失败部分

- 平均路网阻塞起始次数由 40.2 增至 43.2，未通过预设标准。
- 种子 15802 的产能为基线的 94.20%，低于 95% 下限。
- 种子 15802 的单任务能耗为基线的 105.41%，高于 105% 上限。

## 机制解释

五个种子共执行七次世界模型改写，全部是三车联合等待一步。该动作会把连续阻塞事件切分成多个“新起始事件”，所以阻塞起始次数系统性上升。阻塞物理时间的变化仅为 -0.01% 至 +0.47%，说明起始次数部分受到事件分段定义影响，但种子 15802 的产能和能耗越界仍是真实系统性能问题，不能用指标定义解释掉。

V14.4 和 V14.5 证明的是固定 720 秒反事实下的动作排序与影子推荐可靠性。它们不能保证一个推荐被执行后，在完整一小时闭环轨迹中仍然改善最终边界指标。V14.6 的失败说明“可靠排序证据”与“可直接授予控制权限”之间仍需独立的在线安全验证层。

## 后续约束

- 不得在种子 15801-15805 上继续调门槛后把结果作为确认实验。
- 不得删除或覆盖本实验结果。
- 不得降低 V14.4/V14.5 的多步世界模型创新地位。
- 下一方案应采用“多步世界模型提出少量候选 + 高保真数字孪生只验证被选候选”的选择性验证结构。
- 下一开发实验必须使用新的环境种子并单独登记；通过后还需另设未触碰的正式确认种子。
