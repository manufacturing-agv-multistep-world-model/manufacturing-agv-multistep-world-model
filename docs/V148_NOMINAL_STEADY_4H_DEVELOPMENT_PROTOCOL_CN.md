# V14.8 正常生产四小时开发方案

本方案在运行前固定，用于检验冻结的多步物理图世界模型在可生产工况下是否具备闭环可执行性。

- 世界模型：V14.1，模型种子 42、43、44，参数不更新。
- 环境种子：17001-17005，与此前所有开发和确认种子不重叠。
- 物理时长：4 小时。
- 工况：稳定任务到达率，正常通道容量。
- 接管条件：三个模型选择一致，720 秒预测收益不低于 0.15，硬安全约束未激活。
- 接管隔离：720 秒；每次运行最多 8 次。
- 有效性底线：每个成对方法至少完成 20 个任务。
- 配对要求：同一种子下任务数量和完整任务流签名必须一致。
- 其余安全、产能、能效、阻塞和计算时间门槛沿用冻结的 V14.7b-R1 标准。

这是开发实验，不用于正式性能声明。若通过，下一步另选未见种子并预注册正式确认统计方法；若失败，不在种子 17001-17005 上调节模型、门槛或工况。
