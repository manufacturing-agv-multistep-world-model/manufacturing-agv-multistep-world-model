# N1 最终确认分析实现修正记录

日期：2026-08-11

## 发现的问题

冻结协议规定：“完整模型单位任务能耗平均至少比物理保护策略低 1%。”原分析报告展示的四种方法平均值分别为 44.253 Wh/SKU 和 44.715 Wh/SKU，按照冻结文字对应的“方法平均值之比”计算，完整模型降低约 1.03%。

原分析代码却把该效应量门槛实现为：先对每个环境种子计算相对差异，再对 15 个相对差异求平均，得到约 0.98%。这与同一分析程序对产能保持率所采用的“方法平均值之比”口径不一致，也与冻结协议文字不一致。

## 修正原则

- 不重新运行仿真。
- 不修改模型、控制参数、环境种子、任务流或 1% 阈值。
- 1% 最小效应量按冻结协议改为两个方法总体平均值之比。
- 配对重复抽样仍使用逐环境种子相对差异，原置信区间和显著性结果保持不变。
- 原始报告保存为 `confirmation_audit_original_v1.md`，修正报告另存为 `confirmation_audit_corrected_v2.md`，禁止覆盖审计历史。

该修正属于预注册判据的软件实现一致性修复，不是看到结果后降低阈值。论文和补充材料必须同时披露原始判定与修正原因。
