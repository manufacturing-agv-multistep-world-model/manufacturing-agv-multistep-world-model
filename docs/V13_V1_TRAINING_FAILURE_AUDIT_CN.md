# V13-v1 多时间尺度世界模型训练失败审计

## 结论

V13-v1三套模型均完成训练，但不能进入独立诊断或论文结果。原始检查点与训练历史保留在 `world_model_runs/pi_gwm_multistep_v13_multiscale_seed42`、`seed43` 和 `seed44` 目录，不覆盖、不删除。

## 观察结果

- 三套模型均在第1轮取得最低开放环验证总损失，随后验证损失持续上升。
- 种子42的长期风险验证损失由第1轮的0.844上升到第50轮的4.279。
- 种子43的长期风险验证损失由第1轮的0.770上升到第50轮的5.200。
- 种子44的长期风险验证损失由第1轮的0.917上升到第50轮的4.904。
- 未来80步路线风险在训练集和验证集的阳性率分别达到99.74%和99.80%，几乎恒为真，不具备分类辨识能力。
- 未来80步充电排队风险阳性率为10.60%和13.80%，具有可辨识性。

## 根因

1. V13-v1共同微调全部模型参数，使已经通过独立验证的V12短期物理骨干发生漂移。
2. 训练同时使用稀有事件过采样和正类损失加权，形成双重类别补偿，训练分布偏离自然验证分布。
3. 80步路线风险时间窗过长，几乎所有样本均为阳性；该目标没有提供有效监督，反而干扰长期充电风险学习。
4. V13-v1按包含全部物理任务的总验证损失选模，没有把新增长期风险头作为明确的模型选择对象。

## 冻结修正

- V13-v2只预测未来80步充电排队发生风险；短期路线风险仍由V12原有拥堵头负责。
- V12骨干与原有预测头完全冻结，只训练18,625个新增长期充电风险头参数。
- 取消稀有事件过采样，仅保留由训练划分自然阳性率计算的有界正类权重。
- 全程使用开放环输入，消除教师强制比例变化造成的训练与验证状态分布偏移。
- 按验证集长期充电风险损失选择最佳轮次。
- V13-v2写入独立目录 `pi_gwm_multistep_v13_multiscale_v2_seed*`，不覆盖V13-v1证据。

## 论文边界

V13-v1属于方法开发失败记录，不得报告为有效模型。该记录可用于内部可追溯性和补充材料中的模型治理说明，但主文只能使用后续通过预注册独立诊断的V13-v2结果。
