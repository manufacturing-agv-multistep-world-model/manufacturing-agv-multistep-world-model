# V14.8 正常生产开发实验判定

## 结果

五个种子的配对任务流完全一致，每个方法均完成 99-121 个任务，正常工况不存在产能地板效应。两种方法的产能、能效、等待、冲突、阻塞和死锁完全相同。

世界模型在 8097 次决策中没有执行接管，因此预注册的“至少三次接管”门槛失败，不能进入正式闭环确认。

## 原因

- 4310 次没有与基线物理行为不同的有界候选。
- 2002 次三个模型没有一致选择同一个非基线动作。
- 1636 次存在硬安全约束，禁止模型接管。
- 81 次三个模型一致建议非基线动作，但预测收益低于冻结的 0.15 门槛。
- 最高预测收益为 0.1428，不能因为接近门槛而事后降低阈值。

该结果可作为选择性决策系统在低风险工况下主动弃权的开发证据，但不能作为世界模型改善系统绩效的证据。

## 后续边界实验

保持模型、门槛和安全逻辑不变，用相同新种子 18001-18005 测试两个预定义中间工况：稳定到达加压力容量，以及高峰到达加正常容量。这样形成由正常、两种中间压力到极端过载的工况边界，不通过任意调整到达率寻找有利结果。
