# V11 物理边图世界模型预设实验协议

## 固定创新改动

V11 相对 V10 只增加以下可解释结构，不改变训练轨迹、训练/验证划分和独立测试轨迹：

1. 节点物理特征：工厂坐标与节点度数。
2. 道路物理特征：距离、限速、容量和由 S 型运动学公式得到的名义行驶时间。
3. 每辆车分别提取当前位置节点与目标节点的局部图表示。
4. 车辆当前位置、目标节点采用离散分类预测，不允许产生不存在的小数节点。

物理图特征必须随模型检查点保存，保证训练、诊断和规划使用同一版本路网。

## 固定数据口径

- 训练轨迹：与 V9/V10 相同的 24,000 条完整数字孪生转移。
- 数据生成种子：4200。
- 训练/验证划分种子：4200，按完整回合分组后再构造序列。
- 模型种子：42、43、44。
- 训练预测长度：5 步；独立诊断长度：1、3、5、10 步。
- 独立诊断种子：9042，三个模型使用完全相同任务轨迹。

## 预设主要验收条件

1. 相对 V9 三种子均值，1、3、5 步时间平均绝对误差平均至少下降 20%。
2. 相对 V9 三种子均值，1、3、5 步能耗平均绝对误差平均至少下降 20%。
3. 3 步阻塞决定系数不低于 0.60，且阻塞平均绝对误差不得比 V9 恶化超过 5%。
4. 三个模型种子均成功完成，不能仅报告最佳种子。
5. 所有开放环结果必须使用完全关闭教师强制的递归预测。
6. 10 步结果作为超出训练长度的外推压力测试，不作为 3 步控制器的唯一否决条件。

## 决策规则

- 全部主要条件通过：V11 进入多步规划实验，V9/V10 作为结构消融。
- 时间或能耗条件未通过：不得仅凭综合训练损失下降宣称物理预测改进。
- 阻塞预测显著退化：不得进入安全规划实验，必须先修正模型。
