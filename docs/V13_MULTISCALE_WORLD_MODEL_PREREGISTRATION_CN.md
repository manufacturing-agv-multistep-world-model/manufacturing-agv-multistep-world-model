# V13 多时间尺度物理图世界模型预注册

## 研究问题

V12 已证明短时间尺度物理预测有效，但五步控制窗口无法提前识别约二十多分钟后形成的充电排队。V13 不把低层滚动强行延长到80步，而是在保留V12短期路线与充电物理滚动的基础上，增加一个直接预测未来80个低层决策步内是否出现充电排队的长期风险头。长期路线风险不作为新目标，因为初始试算显示其80步阳性率接近100%，不具备辨识意义。

本阶段只检验长期风险预测是否有效，不执行学习模型提出的控制动作，也不比较闭环产出收益。

## 固定数据与模型设置

- 训练轨迹：复用V12已冻结的12个完整回合、共48,000条转换记录。
- 数据种子与划分种子：均固定为4200。
- 训练、验证仍按完整回合分组后再切分窗口，禁止同一回合同时进入训练集和验证集。
- 长期风险窗口：不包含当前步，只预测接下来的80个低层决策步。
- 当前已经出现对应阻塞或排队的样本不参与该类长期风险损失，防止模型把“看见当前事件”冒充提前预警。
- 最后80个无法获得完整未来观察窗的时刻只保留状态数据，其长期风险损失掩码设为0，不把它们标成无风险。
- 三套独立模型种子：42、43、44。
- 每套V13从相同种子的V12最佳检查点初始化；V12物理骨干完全冻结，只训练随机初始化的长期充电风险头，防止破坏已经验证的短期物理能力。
- 长期风险类别权重只由训练划分的阴性/阳性比例计算，并限制在1至20之间；验证集和测试集不参与权重设置。
- 不使用稀有事件过采样，避免与正类加权形成双重补偿。
- 训练30轮，全程使用开放环输入，保存验证集长期充电风险损失最低的轮次，不根据测试结果选择轮次。

## 独立测试设置

- 使用未参与训练和模型选择的新环境种子21313。
- 每套模型独立采集6个完整高负荷回合，每回合最多4,000步。
- 检查开放环滚动第1、3、5和10步的预测。
- 长期风险标签始终表示从对应时刻开始的未来80步窗口，不随开放环滚动步数改变。
- 固定分类阈值为0.5，不根据测试结果重新选择阈值。

## 运行前冻结的继续条件

只有以下条件全部满足，V13才允许进入反事实影子评估：

1. 三套测试数据的充电排队风险阳性比例均在2%至95%之间，确保任务可辨识。
2. 三套模型在开放环第1步的充电排队风险曲线下面积均不低于0.80。
3. 三套模型在开放环第5步的曲线下面积均不低于0.75。
4. 三套模型在开放环第10步的曲线下面积均不低于0.70。
5. 三套模型第1步的平均精确率均至少高出各自阳性比例基线0.15。
6. 至少两套模型在固定0.5阈值下，第1步召回率不低于0.70。
7. 至少两套模型在固定0.5阈值下，第1步精确率不低于0.50。
8. 三套模型第1步的布里尔分数均不高于0.25。
9. 三套模型第1步曲线下面积的变异系数不高于10%。

若任一条件失败，应保留全部结果并停止授予控制权限。不得通过事后缩短80步窗口、改变0.5阈值、删除不利模型种子或更换测试种子使试验转为阳性。

## 通过后的权限边界

通过本试验只说明世界模型能够在较长时间尺度上提供可重复的充电排队预警。下一阶段只能开展不执行动作的影子决策和反事实排序检查，验证风险预测是否能在充电位空闲时提前识别需要错峰的车辆。只有影子评估再次满足单独预注册的条件，才讨论新的小样本闭环控制试验。
