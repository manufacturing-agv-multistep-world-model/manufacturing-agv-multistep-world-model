# V14.1 配对反事实多步世界模型正式协议

## 1. 为什么不直接继续 V14

V14 让模型从当前状态和当前动作直接猜测未来 80 步的绝对能耗、完成任务数和充电排队。可是未来 79 步采用什么动作并没有输入模型，未来任务到达也有随机性，因此绝对结果中混入了模型无法知道的信息。独立测试显示，V14 能识别未来充电风险，也能改善未来综合电效比误差，但终点能耗和完成任务数没有达到预先设定的精度要求，所以禁止进入控制实验。

## 2. V14.1 学习什么

每个样本从完全相同的数字孪生状态复制出两个分支：

1. 基准分支先执行高保真数字孪生规则给出的动作。
2. 候选分支只在第一个动作上采用另一个物理可行的调度动作。
3. 第一个动作之后，两个分支都使用同一套固定的高保真数字孪生规则继续运行。
4. 两个分支保存相同的随机数流，因此接收相同的外部任务流。
5. 在 120、360 和 720 秒三个固定物理时间点，计算候选分支相对基准分支的能耗、完成任务数和充电排队时间变化。

模型预测的是“候选动作减去基准动作”的净影响，不再预测混有未知未来决策的绝对结果。

## 3. 已固定的防漏洞设计

- 候选动作必须改变下一步提议位置、目标节点或路径边，不能只是换了动作编号但车辆实际不动。
- 训练集和验证集按完整仿真轨迹划分，同一条轨迹不能同时出现于两边。
- 目标尺度和稀有影响权重只允许从训练轨迹计算。
- 原 V13 多步物理图世界模型全部冻结，只训练约 5.6 万个反事实参数。
- 采用同一个动作时，模型必须严格输出零差异。
- 交换候选动作和基准动作时，模型输出必须严格变号。
- 仿真跨过目标时刻过多的时间点用掩码排除，但原始越界值保留在审计数据中。
- 正式确认使用新的随机种子 15100，不得读取训练或验证轨迹。

## 4. 正式执行顺序

### 第一步：三随机种子训练

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\121_train_counterfactual_world_model_v141_seeds.ps1 -RequireGpu -CpuThreads 4
```

## 5. 允许继续控制实验的条件

只有下列条件全部通过，才能进入影子控制或闭环控制：

- 至少 500 个独立配对样本。
- 所有目标的有效物理时间覆盖率不低于 85%。
- 720 秒能耗和任务影响的非零比例均不低于 10%。
- 720 秒充电排队影响的非零比例不低于 2%。
- 三模型集成在三个指标上的绝对误差都优于“永远预测零影响”。
- 至少两个指标的轨迹级自助法 95% 区间支持模型优于零基准。
- 能耗和任务的显著影响方向判断准确率均不低于 65%。
- 使用模型挑动作后的平均后悔值至少比始终使用基准规则降低 10%。

任意一项失败都必须停止，不得用该结果宣称控制性能提高。失败后只能分析原因并重新登记新的开发版本，不能在同一正式确认种子上反复调参数。
