# V13-v2 独立阈值校准与确认试验预注册

## 背景

V13-v2在首个独立测试种子21313上通过了全部排序、辨识、召回、校准和跨模型稳定性条件，但三套模型在固定0.5阈值下的精确率为0.436至0.488，未达到预注册的0.50条件。因此该轮必须判为未通过，不能事后修改阈值重新统计同一测试集。

由于模型的曲线下面积为0.923至0.944、平均精确率为0.648至0.664，失败集中在加权二元交叉熵输出与固定0.5操作阈值不匹配，而不是风险排序失效。后续允许保持模型参数完全不变，使用独立校准集确定操作阈值，再在另一个全新确认集上检验。

## 阈值校准

- 模型：冻结现有V13-v2种子42、43和44检查点，不允许重新训练或更新参数。
- 校准环境种子：22313，与训练、验证、首次测试均不同。
- 校准样本：6个高负荷完整回合，每回合最多4,000步。
- 候选阈值：0.05至0.95，固定步长0.005。
- 每套模型分别选择阈值。
- 合格候选必须同时满足精确率不低于0.55、召回率不低于0.65。
- 在合格候选中选择F1分数最高者；若并列，依次选择召回率更高、阈值更低者。
- 任一模型不存在合格阈值时，停止确认试验。

## 独立确认

- 确认环境种子：23313，不参与训练、验证、首次测试或阈值校准。
- 每套模型运行8个高负荷完整回合，每回合最多4,000步。
- 使用校准阶段为对应模型冻结的阈值，不允许根据确认结果调整。
- 检查开放环第1、3、5和10步，长期标签仍为当前无排队时预测后续80步是否发生排队。

## 确认继续条件

只有以下条件全部满足，才允许进入反事实影子决策评估：

1. 三套确认数据的风险阳性比例均在2%至20%之间。
2. 三套模型在第1、5、10步的曲线下面积分别不低于0.80、0.75、0.70。
3. 三套模型第1步平均精确率均至少高出阳性比例基线0.15。
4. 三套模型在各自冻结阈值下的第1步精确率均不低于0.50。
5. 至少两套模型第1步召回率不低于0.65，且任何模型均不低于0.55。
6. 三套模型第1步布里尔分数均不高于0.25。
7. 三套模型第1步曲线下面积的变异系数不高于10%。

本试验通过也只授予影子评估权限，不构成闭环控制性能声明。
