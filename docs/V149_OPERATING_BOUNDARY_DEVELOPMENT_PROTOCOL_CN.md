# V14.9 运行边界开发实验方案

## 目的

在不调节世界模型和接管门槛的前提下，系统地识别正常生产与极端过载之间的运行边界，并检查世界模型的接管频率是否随制造系统压力增加而出现。

## 两个中间工况

1. 稳定任务到达率 + 压力通道容量。
2. 高峰任务到达率 + 正常通道容量。

两个工况均使用种子 18001-18005、四小时物理时长和配对任务流。它们与已完成的“稳定到达 + 正常容量”和“高峰到达 + 压力容量”共同构成预定义的二乘二运行条件。

## 冻结内容

- V14.1 三个模型及其参数不更新。
- 720 秒预测与接管隔离窗口不变。
- 0.15 归一化收益门槛不变。
- 三模型一致、硬安全约束、禁止死锁恢复期接管和每次最多 8 次接管不变。
- 每个成对方法至少完成 20 个任务；任务数量和任务流签名必须一致。

本实验仅用于开发阶段的运行边界判定。若某个中间工况满足全部标准，才对该工况另行使用未见种子设计正式确认；不得在种子 18001-18005 上调节模型或门槛。
