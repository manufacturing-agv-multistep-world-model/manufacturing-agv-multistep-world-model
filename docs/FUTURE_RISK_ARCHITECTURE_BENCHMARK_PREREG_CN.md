# 未来充电排队风险架构对比预注册

## 目的

检验完整V13物理图世界模型的长期风险辨识能力是否超过简单规则和不包含完整物理图机制的学习模型，回应“高分是否由数据本身容易预测造成”的审稿风险。

## 公平性约束

- 所有学习方法使用同一48,000条冻结训练轨迹、相同回合级训练/验证划分、相同未来80步充电排队标签。
- 所有方法使用自然样本分布和相同有界正类权重，不使用测试数据选模。
- 学习模型均训练三个初始化种子42、43和44，按各自验证损失选择最佳轮次。
- 独立测试固定为全新环境种子25313、10个高负荷完整回合；所有方法逐样本配对比较。
- 主要指标为阈值无关的曲线下面积和平均精确率。
- 统计不确定性按完整回合进行2,000次配对重采样，禁止把同一回合内高度相关的时刻当作独立样本。

## 对比方法

1. 规则分数：第二低车辆电量、充电位占用率和场景压力的固定加权组合，不训练。
2. 多层感知机：当前车辆状态、全局状态和动作的扁平输入，无图结构、无历史、无物理边。
3. 循环网络：使用最近20步状态历史，无图结构和物理边。
4. 动态图网络：使用动态车辆特征、节点特征和邻接关系，但不使用V13的静态物理节点/边属性和物理滚动骨干。
5. 完整V13：冻结的多步物理图世界模型骨干加80步充电排队风险头。

## 运行前继续条件

1. 测试集风险阳性率位于2%至20%。
2. V13集成曲线下面积不低于0.80，平均精确率至少高于阳性比例0.15。
3. V13的曲线下面积和平均精确率点估计均高于所有四种基线。
4. 相对多层感知机、循环网络和动态图网络，V13在曲线下面积与平均精确率上的按回合配对重采样95%差值区间下界均大于0。
5. 三套V13初始化的曲线下面积变异系数不超过5%。

全部条件通过，才能在论文中强声明物理图世界模型相对简单预测器具有统计支持的增益；若未通过，应按实际结果缩小结构创新声明。
