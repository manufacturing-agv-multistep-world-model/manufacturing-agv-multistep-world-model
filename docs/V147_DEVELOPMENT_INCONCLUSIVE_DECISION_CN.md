# V14.7 一小时预测窗口隔离实验不确定性决策

V14.7 不进入正式确认实验。原因不是模型安全门失败，而是预设的单任务能耗端点在一个随机种子上不可识别。

- 种子 15903 的基线和 V14.7 均完成 0 个任务，单任务能耗无法计算。
- 种子 15904 的两种方法均只完成 3 个任务，端点方差很大。
- 不允许删除 15903，也不允许只报告其余四个种子。
- 720 秒干预隔离下，固定时间、配对任务流、电量、超时、死锁、物理阻塞时间、冲突、产能保护和计算时间均通过。
- 因单任务能耗标准要求每个运行都可计算，整体结论仍为 NO。

下一开发方案保持同一模型和控制规则，只把固定物理时间提高到 4 小时，并预先增加“每个配对方法至少完成一个任务”的端点可识别条件。使用新种子，不重复使用 15901-15905。
