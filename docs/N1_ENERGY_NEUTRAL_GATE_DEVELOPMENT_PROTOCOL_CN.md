# N1 能耗中性风险门开发协议

冻结日期：2026-08-11

## 修改内容

世界模型权重、训练数据、规划步数、搜索宽度、风险阈值、时间边界和三模型多数票全部保持不变。唯一新增条件为：风险改善型动作的平均预测节能量必须大于或等于 0 Wh；严格节能型和充电错峰型条件保持原样。

零点代表物理能耗中性边界，不是根据失败结果拟合出的经验数值。旧 `evidence_gated` 控制模式完整保留，新版本使用独立名称 `energy_neutral_gated`。

## 分阶段开发

1. 短验证：环境种子 32001，15 分钟，仅检查实现、任务流配对、行为差异和非零接管。
2. 一小时开发：环境种子 37001-37005。继续条件沿用产能至少达到 PI-only 的 90%、能耗不超过 110%、接管率 1%-90%、计算时间不超过 2 秒。
3. 四小时开发：只有一小时开发通过后才设计和运行，重点检查充电排队阶段的能耗方向、冲突和阻塞。
4. 新的独立确认必须使用未参与以上步骤的新种子；旧控制版本的一小时确认不能替代新版本确认。

所有第一版 4 小时失败数据均保留，不得与新版本结果混合。
