# V15.1 效用权重敏感性协议

本分析在模型训练和主确认完成后作为透明的稳健性分析执行，不替代种子 18400 上的预注册主检验，也不得用于修改主检验结论。

固定比较以下四组权重。三个数字依次对应能耗、完成任务量和充电排队时间；计算效用时能耗与排队取负号，完成任务量取正号。

| 名称 | 权重 |
|---|---:|
| 等权 | 1:1:1 |
| 能耗优先 | 2:1:1 |
| 产能优先 | 1:2:1 |
| 排队优先 | 1:1:2 |

所有权重使用同一个训练期冻结尺度、同一批 12 条确认轨迹、同一组 1257 个候选动作和同一组三种子模型集成。完整报告两种学习形式相对未改变动作的后悔值、第一名一致率、绝对预测减直接差值预测的轨迹级差异、自助区间和精确符号检验。

稳健性仅按方向判断：如果四组权重下直接成对学习的平均后悔值均低于绝对结果预测，并且均优于未改变动作，则称点估计方向稳健。区间或符号检验未通过时，不得写成统计显著优势。
