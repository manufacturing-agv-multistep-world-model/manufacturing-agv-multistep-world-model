# V14.7 预测窗口隔离开发方案

V14.7 不训练新模型，也不改变 V14.1 参数、三模型一致规则或 0.15 收益门槛。唯一的控制结构修正是：一次改写执行后，完整 720 秒预测窗口内不得再次改写。

该约束用于保证闭环使用方式与 V14.4/V14.5 的验证条件一致：模型预测的是“候选动作执行一次，之后回到固定数字孪生规则”所产生的 720 秒效果。60 秒冷却会让多个干预效果重叠，破坏这一反事实定义。

- 新开发种子：15901-15905。
- 每次运行：1 小时固定物理时间。
- 最大改写次数：4。
- 改写冷却：720 秒。
- 当前死锁恢复阶段禁止模型接管。
- 两种方法使用相同硬安全保护和相同外生任务流。
- 路网安全主指标采用阻塞物理时间；阻塞起始次数仍完整报告，但不作为单独主判据。

通过条件已写入运行程序。开发数据生成后不得修改这些条件；如果失败，保留结果并停止在这些种子上调参。
