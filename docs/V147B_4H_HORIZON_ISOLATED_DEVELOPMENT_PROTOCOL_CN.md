# V14.7b 四小时预测窗口隔离开发方案

本方案在生成数据前固定，且不改变模型或世界模型决策逻辑。

- 模型：冻结的 V14.1，种子 42、43、44。
- 环境种子：16001-16005，与前述开发和确认数据不重叠。
- 固定物理时长：4 小时。
- 干预隔离：720 秒。
- 单次运行最多改写：8 次。
- 三模型必须一致，且每个推荐继续使用 0.15 平均归一化收益门槛。
- 死锁恢复阶段禁止接管；两种方法使用同一硬安全保护。
- 每个配对方法必须至少完成一个任务，否则单任务能耗不可识别，整个开发方案失败。
- 其余安全、产能、能效和计算时间标准固化在运行程序中。

如果任一标准失败，不在种子 16001-16005 上继续调参，也不进入正式确认实验。
