# V14 双时间尺度世界模型正式实验协议

## 1. 这一步要回答什么

V14 不是新的规则调度器，而是对现有多步物理图世界模型的增强。短时间尺度分支继续逐步预测车辆位置、运动时间、能耗和局部拥堵；长时间尺度分支直接预测当前联合动作执行后，未来 80 个底层决策步内的累计能耗、累计完成任务数和累计充电排队车步数。

本阶段只回答“模型能否可靠预见较长时间范围内的系统结果”，不回答“模型控制是否优于基线”。开放环预测未通过前，不允许进入闭环调度实验。

## 2. 固定数据与防止泄漏

- 数据缓存：`world_model_runs/pi_gwm_multistep_v14_dual_timescale_shared/transitions_schema_v4_long_seed4200.pkl.gz`
- 数据规模：12 个完整回合，每回合最多 4000 步，共 48000 条转移。
- 当前任务流：第四版独立到达流、拥堵归因可见、满物理数字孪生、rush 场景。
- 模型随机种子：42、43、44。
- 训练集和验证集按完整回合划分，然后才构造窗口，任何窗口不得跨越回合。
- 未来标签、类别权重和数值缩放全部在划分后计算；验证集不参与权重、缩放或阈值选择。
- 三个模型种子共享完全相同的外生轨迹、数据划分和物理参数，只改变网络初始化。

## 3. 可解释标签

每个长时间窗口包含当前动作对应的转移及其后续转移：

- 累计能耗：将缓存中的标准化能耗还原为瓦时后求和。
- 累计完成任务数：将每步完成量还原为实际任务数后求和。
- 累计充电排队车步数：将按车队规模标准化的排队量还原后求和。

窗口不足 80 步、转移编号不连续或在窗口结束前提前终止时，该标签被遮罩，不参与损失。

## 4. 正式训练设置

- 初始化：分别使用随机种子 42、43、44 的 V13 检查点。
- 冻结部分：冻结已经验证的 V13 物理图编码、多步状态转移、拥堵预测和未来风险头。
- 训练部分：只训练 V14 长时间尺度终端预测头。
- 优化器：AdamW；学习率 0.0003；权重衰减 0.0001。
- 训练轮数：最多 30 轮；按验证集长周期终端损失选择检查点。
- 训练窗口：10 步开放环；长周期监督窗口：80 步。
- 稀有充电排队权重：只由训练集阳性和阴性比例计算，上限为 20。
- 数值缩放：只用训练集有效标签的第 75 百分位数，最小值为 1。

## 5. 正式训练完整性门槛

- [x] 三个随机种子均完成训练并生成检查点、训练历史和参数文件。
- [x] 三个检查点的模型版本均为 V14，物理图结构和 V13 初始化来源可追溯。
- [x] 三个随机种子使用相同的数据签名、回合划分、长周期窗口和标签缩放。
- [x] 每个模型只有 V14 终端头参数可训练，其余 V13 参数保持冻结。
- [x] 所有训练和验证损失有限，无空值、无无穷大、无梯度溢出。
- [x] 最佳检查点由预先指定的验证集长周期终端损失选择，而不是由闭环结果反向选择。

## 6. 独立开放环诊断门槛

训练完成后，使用未参与训练、划分或阈值设置的新环境种子采集完整轨迹。三个模型必须在完全相同的测试样本上评估。

- [ ] 累计能耗的归一化平均绝对误差不高于 0.25。
- [ ] 累计完成任务数的归一化平均绝对误差不高于 0.35。
- [ ] 能耗与完成任务数的 Spearman 等级相关系数均不低于 0.50。
- [ ] 在实际完成任务数大于零的窗口中，预测单位任务能耗与真实单位任务能耗的 Spearman 等级相关系数不低于 0.50。
- [ ] 充电排队阳性比例位于 2% 到 20%，保证任务可识别且不是极端失衡。
- [ ] 由累计充电排队输出形成的排队风险判别，其曲线下面积不低于 0.80，平均精确率至少比阳性比例高 0.15。
- [ ] 三个模型种子的主要误差指标变异系数不高于 10%。
- [ ] 与仅短期 V13 累加预测相比，V14 在单位任务能耗排序或充电排队预测上至少有一项具有配对置信区间支持的改进，且另一项不显著退化。

只有上述完整性和开放环门槛通过，才允许设计 V14 的影子决策和后续闭环开发。即使通过，也不能直接宣称闭环性能提升。
