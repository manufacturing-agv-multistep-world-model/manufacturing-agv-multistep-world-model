# V15.1 配对目标形式正式确认结果决策

## 1. 决策结论

V15.1 的正式确认协议完整通过，但事前冻结的科学支持门未通过。该结果应保留并报告为：直接配对效应监督相对“分别预测两个绝对结果后相减”具有较大的平均优势和更高的 Top-1 一致率，但轨迹间异质性使 95% 区间跨零，因此尚未证明稳定的形式优越性。

这不是世界模型失败。世界模型相对 DT-aware 保留动作的正式排序价值由独立的 N6 证据支持；V15.1 回答的是更窄的问题，即这种价值能否稳定归因于“直接配对效应”这一目标形式。

## 2. 冻结确认结果

- 数据种子：18400。
- 独立完整轨迹：12 条。
- 配对候选：1,257 个。
- 完整排序状态：410 个。
- 两种形式使用相同冻结 V13 骨干、相同 56,457 参数动作价值头、相同训练样本、相同轨迹划分、相同训练日程和相同三个初始化种子。
- 直接配对效应监督：平均遗憾 0.34657，规则相对遗憾降低 31.5%，Top-1 一致率 40.2%。
- 绝对结果后相减：平均遗憾 0.46049，规则相对遗憾降低 9.0%，Top-1 一致率 17.6%。
- 绝对结果减直接配对的平均遗憾差：+0.11392。
- 轨迹自助法 95% 区间：[-0.00699,+0.22456]。
- 12 条非零轨迹中 8 条支持直接配对监督；精确双侧符号检验 $p=0.387695$。

## 3. 冻结门判定

- [x] 直接配对监督的平均排序遗憾更低。
- [ ] 轨迹自助法 95% 区间下界高于零。
- [ ] 至少 9/12 条轨迹支持直接配对监督。
- [x] 直接配对 Top-1 一致率不低于绝对结果形式。

协议完整性：**PASS**。

稳定形式优越性的科学支持：**NO**。

## 4. 后确认权重稳健性

在模型、轨迹、候选动作和训练尺度全部固定后，透明评估四组能耗/产能/排队权重。绝对结果减直接配对的平均遗憾差在 1:1:1、2:1:1、1:2:1 和 1:1:2 下分别为 +0.1139、+0.2182、+0.0556 和 +0.1606，方向全部支持直接配对监督。只有排队优先 1:1:2 的 95% 区间完全高于零。

该分析只能支持点估计方向稳健性，不替代事前冻结的等权主确认，也不能表述为所有制造偏好下均显著优越。

## 5. 论文允许表述

允许：直接配对效应监督在正式确认中取得更低的平均遗憾和更高的 Top-1 一致率，并在四组固定效用权重下保持有利的点估计方向。

必须同时说明：主配对区间跨零，且仅 8/12 条轨迹支持直接配对监督，因此没有建立稳定或普遍的形式优越性。

禁止：更换确认种子、删除不利轨迹、修改冻结门槛，或把后确认权重分析作为新的主确认结果。
