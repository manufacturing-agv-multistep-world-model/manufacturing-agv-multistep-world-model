# 多步物理图世界模型的 JMS 论文主张边界

## 可以主张

1. 构建了面向制造物流系统的多步物理图世界模型，联合表示路网拓扑、车辆状态、能耗、任务完成和排队风险。
2. 模型通过独立种子上的多步开环诊断、冻结阈值确认和反事实动作排序检验。
3. 在非执行影子模式中，模型能识别与基线不同的候选动作，并通过冻结门槛与三模型一致性控制不确定性。
4. 闭环安全层在正常、需求压力、容量压力和联合过载工况中保持电量、超时和死锁保护；模型在证据不足时主动弃权。
5. 工况矩阵揭示通道容量限制比单纯提高任务到达率更容易造成系统失稳，为制造系统设计提供决策价值。

## 不可以主张

1. 不宣称世界模型显著提高产能。
2. 不宣称世界模型显著降低单位任务能耗。
3. 不把两个稀疏且方向不一致的闭环接管事件描述为性能改善。
4. 不把开发实验写成正式确认实验。
5. 不因正常工况最高预测收益 0.1428 接近 0.15 而事后降低门槛。

## 推荐论文定位

论文主线定位为“面向能耗感知与鲁棒 AGV 物流的制造系统级高保真数字孪生和多步反事实世界模型决策框架”。创新重点是可信预测、反事实评估、安全选择性决策和跨仿真验证，而不是新的 AGV 调度器在所有工况下击败规则方法。
